## 📌 Projeto em destaque

### 📚 MADR API — Gerenciamento de livros e romancistas

API RESTful desenvolvida com **Python + FastAPI** para gerenciamento de usuários, livros e romancistas.

- 🔐 Autenticação JWT e proteção de rotas.
- 📚 CRUD, filtros, pesquisa e paginação.
- 🗄️ PostgreSQL, SQLAlchemy Async e migrations com Alembic.
- ✅ Testes automatizados com **100% de cobertura de linhas e branches**.
- 🐳 Containerização com Docker e Docker Compose.
- ⚙️ Integração contínua com GitHub Actions.
- ☁️ Deploy no Render com banco PostgreSQL no Neon.
